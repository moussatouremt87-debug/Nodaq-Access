# Émettre une facture

Une facture naît en **brouillon**. Tant qu'elle est dans cet état, elle n'existe
pour personne : ni dans votre chiffre d'affaires, ni dans vos impayés, et le
client n'en sait rien.

L'**émission** lui donne son numéro définitif et archive son PDF, qui devient
inaltérable.

## Comment faire

1. Écran **Factures**, ouvrez la facture
2. Bouton **Émettre**

## Si l'émission est refusée

Le refus dit toujours ce qui manque. Les deux cas courants :

**Attestation TVA réduite.** Une ligne à 10 % ou 5,5 % exige une attestation
signée par le client — c'est une obligation fiscale sur les travaux de
rénovation, pas un caprice du logiciel. Récupérez-la, puis cochez la case
**Attestation TVA réduite reçue** sur la facture.

**Franchise en base de TVA.** Si votre profil déclare la franchise (art. 293 B
du CGI), aucune ligne ne peut porter de TVA. Corrigez le profil d'entreprise ou
les lignes.
