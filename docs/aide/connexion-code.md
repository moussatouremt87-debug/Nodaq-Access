# Se connecter

Vous entrez votre adresse et votre mot de passe. Sur un appareil que nous ne
connaissons pas encore, un **code à six chiffres** vous est envoyé par courriel.

Une fois ce code saisi, **nous ne vous le redemanderons plus pendant trois
mois** sur cet appareil.

## Le code n'arrive pas

Dans l'ordre, c'est presque toujours l'une de ces trois causes :

1. **Vérifiez l'adresse affichée à l'écran.** Elle est écrite en toutes lettres
   sous le titre. Une lettre manquante et le code part dans le vide.
2. **Regardez les indésirables.** C'est là qu'il atterrit le plus souvent la
   première fois.
3. **Demandez-en un nouveau** par le lien sous le champ. Attention : le code
   précédent cesse alors de fonctionner. Utilisez toujours le dernier reçu.

Si l'adresse est fausse, utilisez **Se déconnecter et recommencer** au bas de
l'écran, puis créez votre compte avec la bonne adresse.

## Le code est refusé

**« Ce code n'est plus valable »** — vous saisissez un code d'un courriel
précédent. Chaque nouvelle demande annule la précédente.

**« Il vous reste N essais »** — au bout de cinq essais le code meurt, pour
qu'on ne puisse pas le deviner. Demandez-en un neuf.

Un code est valable **dix minutes**.
